# UnityCrackTool

A lightweight utility for Unity development and crack analysis.

## Overview

NETexplorer provides essential functionality for analyzing and working with Unity projects. It's designed to be fast, efficient, and easy to integrate into your workflow.

## Features

- ✓ Fast processing
- ✓ Easy integration
- ✓ Cross-platform support
- ✓ Clean CLI interface

## Requirements

- .NET Framework 4.7+ or .NET 6.0+
- Visual Studio 2019+ (or any C# compatible IDE like VScode)
- Windows/Linux/macOS

## Building

### Using Visual Studio

1. Clone the repository:
   ```bash
   git clone https://github.com/4D4J/NETexplorer.git
   cd NETexplorer
   ```

2. Open `NETexplorer.sln`

3. Build the solution (Ctrl+Shift+B)

### Using Command Line

```bash
dotnet build --configuration Release
```

## Installation

1. Build the project following the instructions above
2. Output files will be in `bin/Release/`
3. Copy to your desired location

## Usage

```bash
./NETexplorer [options] [arguments]
```
